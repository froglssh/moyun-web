# 墨韻 Moyun · 依文繪意

以 WebGL2 流體模擬呈現水墨，在瀏覽器中依古典詩文的原文、主旨和敘事關係構思畫作，並題寫原文。

## 依文創作

內建 543 篇作品、240 位作者，涵蓋詩、詞、文、曲、詩經、楚辭、辭賦與小說。朝代、體裁、作者和全文檢索均保留。

創作管線：**原典 → 主旨／修辭 → 取景段落 → 有依據的景物 → 意境解析 → 構圖與筆墨 → 原文題跋**。

### 意境解析與構圖（literary_yijing.js）

物象只回答「畫什麼」，意境決定「怎麼畫」。每次創作在核定物象之後，再解析五個層面，只影響構圖與墨色，不新增任何物象：

| 層面 | 內容 | 對畫面的作用 |
|---|---|---|
| 情 | 十種情感基調：孤寂清寒、蕭瑟羈愁、閒適恬淡、空靈禪寂、雄渾豪放、思念離愁、明麗生機、沉鬱悲愴、家國憂思、超然曠達 | 墨量濃淡、乾濕、皴法、留白比例、主體大小 |
| 時 | 時辰（晨・晝・暮・夜）、季節、天候（晴・雨・雪・風・煙霧），先剔除「疑是地上霜」「千堆雪」等比喻 | 夜色通染、暮色赭紅、雪景烘托、細雨斜筆、雲斷山腰 |
| 境 | 郭熙三遠（平遠・高遠・深遠）、空間尺度、視覺焦點、有我／無我之境 | 地平線高低、主景側與留白側、主體落在三分點 |
| 法 | 披麻皴、斧劈皴、米點皴或不皴；烘雲托月；山體留白為雪 | 山石筆法、天色與月輪處理 |
| 讀 | 意境解讀與構圖說明 | 閱讀器與創作提示框中顯示 |

- 49 篇名篇（江雪、靜夜思、天淨沙・秋思、楓橋夜泊、登高、望廬山瀑布、黃鶴樓送孟浩然、山居秋暝、鹿柴、前赤壁賦、水調歌頭等）有人工校訂的意境與構圖；其餘以詞彙推定，介面標示「名篇意境校訂」或「詞彙意境推定」。
- 繪畫器由遠而近分層落筆：天色烘托 → 日月 → 遠山（淡墨不皴）→ 中山、近山（皴擦點苔，山腳淡出為雲）→ 水 → 中景人家亭橋 → 近岸樹石 → 點景人物舟馬 → 天候。
- 範例：江雪以灰墨烘染天空與寒江、群山留白為雪，孤舟只佔極小比例；靜夜思以夜色留出明月與一地清光；楓橋夜泊月落不留月，只以朱砂點一盞漁火；登高讓詩人立於高崖，長江遠在崖下。
- 「山水畫境風格」手動選項只改筆墨情調與留白，不改原文時令與物象。
- 唯一不屬於物象的筆劃是 ambient：低墨量、大面積的天色與地色渲染，測試會確認它不構成可辨認物象。

- 96 篇作品有專篇釋義，處理容易誤畫的比喻、否定、詞牌名、夢境、回憶和時序；其餘 447 篇採保守文本取景，介面明確標示分析層級。
- 畫面只渲染計畫列出的物象；不因風格或情緒自動加上鳥、船、月亮、雪山。
- 閱讀視窗顯示主旨、原文依據、語義推定、取景方式、畫面限制與題字預覽。
- 《采薇》《桃花源記》《夜雨寄北》《破陣子》《岳陽樓記》提供分景選擇，區分不同時間或敘事層次。
- 短詩詞題寫原文全文；長篇以完整語句節錄，落款標示「全文／節錄」。字數不適合一頁時，題跋可翻頁，原典全文一直保存在閱讀器中。
- 落款標示原作者與篇名，使用「依文繪意」創作印，避免把程式生成圖畫偽託成古人書畫。
- 貼入可辨認的原詩或原篇連續片段，會使用典庫對應專篇釋義。
- PNG 匯出包含畫作、本頁題字、落款和印章；長題跋可翻頁後逐頁典藏。

## 本機與雲端

本機引擎是**規則分析、專篇釋義與程序筆墨**，並非重新訓練的語言模型或影像模型。它能限制缺乏文本依據的景物，但不能保證所有複雜古文的哲思、用典與藝術表現已完全解讀。保守分析須與原典精讀交叉核對。

在「意境創作 → ⚙️ AI 創作大腦設定」可選擇四種大腦：

| 大腦 | 金鑰申請 | 預設模型 | 說明 |
|---|---|---|---|
| 本機引擎 | 免金鑰 | — | 規則分析、專篇釋義與意境解析，離線可用。 |
| Google Gemini | [AI Studio](https://aistudio.google.com/app/apikey) | `gemini-3.8-flash` | 有免費層（用量上限）；Gemini 2.5 已限既有使用者。 |
| OpenAI GPT | [OpenRouter](https://openrouter.ai/settings/keys)（預設）／[OpenAI Platform](https://platform.openai.com/api-keys) | `gpt-6-luna` | OpenAI 官方 API 不允許瀏覽器直連（CORS），純網頁預設經 OpenRouter 轉接同款模型；也可填自架的 OpenAI 相容端點。需先儲值。 |
| Anthropic Claude | [Claude Console](https://platform.claude.com/settings/keys) | `claude-sonnet-5-5` | API 與 Claude 訂閱分開計費，需先購買額度。 |

- 每家金鑰分開儲存在本機瀏覽器，可隨時「清除此金鑰」；模型可從清單選擇，或填自訂模型代碼（各家改版時不必改程式）。
- 「🔌 測試連線」分兩步：①查詢模型（不耗額度，確認金鑰與模型代碼）②極短生成（確認額度與付費已開通）。錯誤會轉成中文說明：金鑰無效、模型不存在、額度不足、請求過快、網路或防火牆阻擋等。
- 三家都以 JSON Schema 結構化輸出回傳主旨、取景與意境欄位；若模型不接受結構化參數，會自動改以提示詞要求 JSON 再試一次。回覆逐項回查原文，不存在的引句、景物或衝突結果退回本機構思；名篇意境校訂不被覆寫。
- 創作時會將該篇文字（圖片模式含所選圖片）直接從瀏覽器送到所選服務，費用依各家帳戶計算。雲端失敗時自動改用本機構思，並在意境說明中寫明原因。

原有互動濃墨、朱砂、清水、洗紙、古琴與日夜主題均保留。「依文落筆」會隨機選篇並走同一套原文構圖管線。主畫布與本機詩文分析無網路依賴；線上字型、PDF.js 與選配雲端分析需要網路，PDF 的離線使用須另行快取依賴。

## 開啟與驗證

```bash
python3 -m http.server 8000 --bind 127.0.0.1
# 瀏覽 http://127.0.0.1:8000/
node scripts/test-literary.cjs
node scripts/test-cloud.cjs
node scripts/build-literary-catalog.cjs
```

需支援 WebGL2 及浮點渲染目標的瀏覽器。無需打包或安裝 npm 依賴；測試與全庫分析索引產生器需要 Node.js。
